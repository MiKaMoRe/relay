# Relay
> [!WARNING]  
> Vibe Coded

Личный AI-ассистент, который сам решает, какой специализированный агент и какая локальная модель нужны для вашего запроса — код, поиск информации, тексты, изображения или что-то попроще. Работает полностью на вашей машине через [Ollama](https://ollama.com), без облачных API и без отправки данных куда-либо наружу.

Проект специально сделан простым и заточен под форки — чтобы можно было быстро подстроить его под свой набор локальных моделей и свои сценарии, не разбираясь в сложном фреймворке.

## Почему так

Большинство мульти-агентных фреймворков рассчитаны на облачные API и требуют разбираться в абстракциях самого фреймворка. Relay — это осознанно простой, прозрачный диспетчер: один FastAPI-сервер, один минималистичный чат на чистом HTML/JS, и конфигурация агентов — в обычных текстовых файлах, а не в коде.

## Как это работает

1. Вы отправляете сообщение (и, опционально, изображение) в чат
2. Лёгкая быстрая модель-роутер читает запрос (с учётом истории диалога) и определяет, к какой категории он относится
3. Диспетчер берёт системный промпт и модель для этой категории из файлов конфигурации
4. Соответствующая специализированная модель отвечает на ваш запрос

Если в сообщении есть изображение — оно автоматически обрабатывается vision-моделью, без ручного переключения режимов.

```
Вы → чат (HTML) → FastAPI → роутер (классификация) → нужный агент + модель → ответ
```

## Возможности

- **Автоматический роутинг** — не нужно вручную выбирать агента, диспетчер сам определяет категорию запроса
- **Разные модели под разные задачи** — быстрая лёгкая модель для роутинга и простых вопросов, более тяжёлая — для кода, творческих задач, анализа изображений
- **Память в диалоге** — агенты видят историю переписки, включая ранее отправленные изображения
- **Конфигурация в файлах, не в коде** — промпт, описание и модель каждого агента лежат в отдельных `.md`/`.txt` файлах
- **Минималистичный веб-чат** — один HTML-файл: markdown в ответах, drag-and-drop для изображений, вставка картинки из буфера обмена (Ctrl+V), тёмная тема из коробки
- **Полностью локально** — все запросы уходят только в Ollama на вашей машине

## Быстрый старт

### 1. Установите зависимости

```bash
pip install fastapi uvicorn ollama python-multipart
```

### 2. Установите Ollama и подтяните модели

Инструкция по установке Ollama: [ollama.com](https://ollama.com)

Модели, которые нужны агентам по умолчанию, перечислены в `agents/*/model.txt`. Подтяните те, что указаны там (или замените на свои — см. раздел [Настройка агентов](#настройка-агентов)):

```bash
ollama pull qwen3:8b
ollama pull qwen3.5
```

### 3. Запустите сервер

```bash
uvicorn app:app --reload
```

Документация API появится на `http://localhost:8000/docs`.

### 4. Откройте чат

Откройте `index.html` прямо в браузере (двойной клик — работает без веб-сервера). По умолчанию чат обращается к `http://localhost:8000`; при необходимости адрес меняется через иконку настроек в интерфейсе.

## Настройка агентов

Все агенты описываются файлами в папке `agents/`, без единой строчки Python-кода:

```
agents/
  _router/
    model.txt           — модель для классификации запросов
    system_prompt.md     — инструкция роутеру (шаблон со списком категорий)
  code/
    description.md        — когда роутер должен выбрать этого агента
    system_prompt.md       — системный промпт агента
    model.txt               — модель Ollama для этого агента
  research/
    ...
  creative/
    ...
  general/
    ...
  vision/
    ...
```

**Чтобы поменять модель или поведение агента** — просто отредактируйте соответствующий файл, перезапускать код не нужно.

**Чтобы добавить нового агента** — создайте новую папку с тремя файлами (`description.md`, `system_prompt.md`, `model.txt`) и перезапустите сервер. Диспетчер подхватит её автоматически и начнёт учитывать при роутинге.

**Чтобы убрать агента** — удалите его папку.

Единственное исключение — папка `vision`: она не участвует в текстовой классификации, а выбирается автоматически при наличии изображения в сообщении или в истории диалога.

## Использование под свои модели

Проект не привязан к конкретному набору моделей. Если у вас уже стоят другие модели в Ollama:

1. Откройте `agents/<имя_агента>/model.txt`
2. Замените название модели на своё (должно совпадать с тем, что показывает `ollama list`)
3. Сохраните — новая модель подхватится при следующем запросе

Так же можно менять и системные промпты под свой стиль работы — они читаются заново при каждом запуске сервера.

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/chat` | Основная точка входа: текст, изображение или и то, и другое |
| `GET` | `/agents` | Список доступных категорий агентов и их описаний |
| `GET` | `/health` | Проверка, что сервер жив |

`POST /chat` принимает `multipart/form-data`:
- `message` — текст запроса
- `image` — файл изображения (опционально)
- `history` — JSON-массив предыдущих сообщений диалога (опционально)

## Форкайте и настраивайте

Проект сделан так, чтобы форк занимал минуты: замените модели в `model.txt`, поправьте промпты под свои задачи, добавьте свои агенты — и получите личного ассистента, полностью соответствующего вашему железу и рабочим привычкам.
